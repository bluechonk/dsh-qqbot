# 验收清单

功能已经堆了不少，但**大部分只在单测里验证过**。这份清单把「该看什么、在哪看、看不对怎么查」列全，照着走一遍即可。

## 准备

重启 DSH Desktop（很多修复要重启才生效）。确认插件活着：

```bash
curl -s http://127.0.0.1:<宿主端口>/qqbot/im-qqbot/bind
# 期望：200，phase=bound
```

端口每次都变，用这条拿：

```powershell
$pids = (Get-Process 'DeepSeek Harness').Id
Get-NetTCPConnection -State Listen |
  Where-Object { $pids -contains $_.OwningProcess } |
  Select-Object -ExpandProperty LocalPort -Unique
```

数据目录：`~/.dsh-qqbot/`

## 一、基础连通

| 验什么 | 怎么做 | 期望 | 不对时看 |
|---|---|---|---|
| 私聊通 | QQ 私聊发「在吗」 | 有回复 | `startup.log` 有没有 apply() |
| 群聊通 | 群里发「大肥鱼」 | 有回复 | `proactive-scores.jsonl` 有没有记录 |
| 被 @ 必回 | 群里 @ 她 + 随便说点 | 必回 | 日志里 `decision=mentioned` |

> **完全没有日志** → 消息没到插件，是 QQ 平台没推（群消息权限或额度），代码侧无解。

## 二、自主接话与时机

| 验什么 | 怎么做 | 期望 |
|---|---|---|
| 该接的接 | 群里发「这个报错怎么解决啊」（别 @） | 大概率接 |
| 不该接的不接 | 连发「哈哈哈」「666」「打卡」 | 不接 |
| 别连珠炮 | 她刚说完话，立刻再抛一句 | 大概率不接（`bot-just-spoke`） |
| 别抢话 | 群里快速刷 20+ 条 | 不插嘴（`busy-group`） |
| 连发该接 | 同一个人连发 2~3 条没人应 | 更容易接（`consecutive-sender`） |
| 喊名字必应 | 刷屏中也喊「大肥鱼」 | 必应（名字压过一切时机特征） |

**怎么确认判定原因**：看 `~/.dsh-qqbot/proactive-scores.jsonl`，每行有 `score` / `reason` / `recentMessages` / `consecutiveSameSender` / `sinceBotSpokeMs`。

```bash
# 看最近 10 条判定
tail -10 ~/.dsh-qqbot/proactive-scores.jsonl
```

## 三、拟人化

| 验什么 | 怎么做 | 期望 |
|---|---|---|
| 不秒回 | 观察回复到达时间 | 有停顿感，但不至于等到烦躁 |
| 会沉默 | 多聊几句 | 偶尔回 `[skip]`（即完全不发消息） |
| 不复读 | 连续问类似的问题 | 说法不重样 |
| 记得称呼 | 群里说「叫我老王」，之后再看 | 会叫「老王」 |
| 人格一致 | 随便聊几句 | 傲娇、≤40 字、不分段、不写括号动作 |

**群友档案检查**：

```bash
cat ~/.dsh-qqbot/people.json
# 期望：能看到 openid、name、aliases、count
```

> 档案按 `appId|群或私聊|openid` 隔离——同一个群被两个机器人加，档案各自独立。

## 四、设置页

| 验什么 | 怎么做 | 期望 |
|---|---|---|
| 保存能成功 | 改任一开关 → 保存 | 提示保存成功，不再报错 |
| 思考模式 | 下拉选「关闭」→ 保存 | 保存成功，回复变快 |
| 默认值正确 | 看面板初始值 | 要求 @ 关、流式关、工具结果关、自主接话开 |

> 若报「不支持的字段: xxx」→ 宿主跑的是旧代码，重启。
> 若报「无法定位 profile 目录」→ 是新 bug，回报。

## 七、排障速查

| 现象 | 先查 |
|---|---|
| 完全不回 | `startup.log`（插件起来没）→ `proactive-scores.jsonl`（消息到了没） |
| 只回私聊不回群 | 群的推送权限；`raw-events.jsonl` 有没有群消息 |
| 回复慢 | 模型耗时 vs 目标延迟；`replyDelayMs` 调低或设 0 |
| 觉得太吵 | `proactive.minScore` 调高（0.55 → 0.7）、`proactive.maxPerHour` 调低 |
| 觉得太闷 | `proactive.minScore` 调低、`proactive.maxPerHour` 调高 |
| 设置页存不上 | 重启宿主；仍不行回报（附报错原文） |

## 八、日志位置总表

```
~/.dsh-qqbot/
├── startup.log              # 插件启动留痕（失败原因）
├── proactive-scores.jsonl   # 自主接话判定（分数/理由/时机特征）
├── raw-events.jsonl         # 未知网关事件（探测平台推不推某类事件）
├── people.json              # 群友档案
└── model-prefs.json         # per-peer 模型与预设偏好
```
