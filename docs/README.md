## 排查入口

机器人不回话、回复不对、配置没生效时，**不要靠猜**：

```bash
# 插件层：宿主状态、绑定、生效配置、门控判定、丢弃留痕、数据目录
pwsh -NoProfile -ExecutionPolicy Bypass -File .agents/skills/qqbot-log-triage/scripts/qqbot-state.ps1

# 会话层：模型有没有被调用、每轮以什么原因结束
cd .agents/skills/qqbot-session-triage/scripts
node session-log.mjs scan 'qqbot:<appId>:group:<群openid>'
```

排查分层的理由与证据分级见 [内部机制.md](内部机制.md)。
